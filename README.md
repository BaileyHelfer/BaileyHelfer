## About Me

I graduated from the University of Michigan-Dearborn with a degree in Computer and Information Science. Since then, I’ve worked heavily in industrial software, building systems that connect computer vision, machine learning, backend APIs, databases, frontend interfaces, and production infrastructure.

At USS Vision, I lead development on containerized machine vision systems deployed across manufacturing plants. My work includes Python services for camera acquisition and triggering, GPU-based inference pipelines, PostgreSQL databases, FastAPI and Flask backends, React and Flutter interfaces, Apache Superset dashboards, and Docker-based deployments.

I enjoy solving the kind of problems that show up in real environments: offline systems, high image throughput, edge hardware, factory networks, production databases, customer-facing tools, and real-time constraints.
